# stardew.earthy-recolor-missing

Real AI: 0

This mod simply adds some edited assets from mods that don't have a patch for Daisy's Earthy Interface mod.

Base Mod:
- Earthy Interface

Mods Changed:
- Generic Mod Config Menu
- Deluxe Journal
- Event Lookup
- Vanilla Plus Professions
- Stardew and Chill - Music Replacer
- Better Jukebox
- Ferngill Simple Economy

This is a replacement mod so all files will overwrite the originals. Make a backup if you'd like.

Installation:
- Download the file/s you want/need
- Extract the folder/s
- Paste the folders you want into your mod folder
- Overwrite all files
